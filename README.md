# Artes Nobiles

A simple, responsive, static website. The publishable website is in `dist/`. At desktop widths of 960px and above, each product’s copy is on the left and its image is on the right; smaller screens keep the stacked category, image, and details layout.

Workflow preference: push completed website updates directly to `master` for immediate production deployment.

Repository: [brantlymillegan/artes-nobiles-website](https://github.com/brantlymillegan/artes-nobiles-website). GitHub Actions deploys the default branch to GitHub Pages. See [GITHUB_PAGES.md](GITHUB_PAGES.md) for the exact DNS records for `artesnobiles.com` and HTTPS. Run `python3 scripts/build_pages.py` to validate and assemble the public release in `_site/`; the workflow publishes only those selected files.

Run a local preview with `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`, then open http://127.0.0.1:4173.

The Christmas Story reading proof is reference material only and is not included in this project. The supplied cover is included. The ROSARIUM preview uses the latest approved light and dark app videos from “Create Rosarium app animation”. The book's purchase link and release information can be added when available.

The site is deployed on GitHub Pages with artesnobiles.com configured as its custom domain. GoDaddy DNS has been verified to point to GitHub Pages. HTTPS is enabled for the apex and www domains, and HTTP/www requests redirect to https://artesnobiles.com/.

The header uses the latest full-name SVG seals supplied in “Design company logo”, from `output/artes-nobiles-logos/animation-full-growth/`: black in light mode and white in dark mode, following the System / Light / Dark selection. All four SVGs and the supplied motion helper are copied unchanged. The artwork spells “Artes Nobiles” and includes the approved rounded joined vine base. The two-second animation plays once on page load, then settles into the matching static logo. Mouse hover, a tap/click, or keyboard focus replays it with a 240 ms crossfade from the static version. Repeated triggers during playback are ignored. Both theme variants stay synchronized, and reduced-motion preferences keep the logo still. Static images remain the fallback if JavaScript or animation loading fails. The footer remains text. The favicon uses the same static black seal, with the curved name removed, a solid white disk inside the outer circle, and transparency outside. Its SVG retains the original logo paths and both borders; the ICO fallback provides 16, 32, and 48 px versions.

Link previews use the page title “Artes Nobiles” and description “Sacred art, modern medium” in the HTML title, standard description, Open Graph, and X/Twitter Card metadata. `dist/og.png` is a 1200×630 opaque PNG with the exact white static full-name logo centered on the dark background `#252a32`; no additional text is drawn into the image. Image dimensions, MIME type, alternative text, and absolute HTTPS URLs are included in the initial HTML so preview crawlers do not need JavaScript.

Brand rules for this site:
- Do not invent company or product slogans or mottos.
- Render the ROSARIUM wordmark with its official Noto Serif variable font: weight 720 and 0.18em letter spacing.
- In every visible book title, set “The” smaller and italic, vertically centered to the left of “Christmas Story.”
- Center “The” against the main letters’ bodies, excluding the long tail of the “y.” The shared title component uses a .744em alignment box and reserves .233em below for the descender, in both the navigation and book heading.
- Match the cover’s exact typefaces: Big Caslon Medium for “Christmas Story” (tracking −0.018em) and Minion Variable Concept Italic for “The” (weight 400, optical size 21.22). The menu and book heading use outlined SVG glyphs from those actual font files, with accessible text, so rendering does not depend on installed fonts. Keep the existing website size ratios and vertical centering. Source measurements and the CoreText outline generator are in `output/christmas-title-fonts/`; no cover font files or book PDF are published.
- Show the app inside the actual Samsung Galaxy S26 device image, keeping the entire status bar within the screen corners.

The Galaxy S26 photograph is the official Samsung base-model Front2 Black asset. The video uses that same photograph around actual Android app footage. Both v6 MP4 files are copied unchanged from `output/rosarium-animation/v6/`: silent, 40 seconds, 60 fps, H.264 with fast start. A 519×1073 frame crops the 600×1200 export’s padding so the phone stays exactly 365px high on mobile, 390px at intermediate widths, and 430–460px on desktop. The original transparent opening frame provides the exact phone outline and a still fallback. The video autoplays muted and loops inline, follows the resolved theme while preserving playback position, scales to 104% on hover, and links to rosariumprayer.com in a new tab/window. A separate pause/play control remains available; reduced-motion preferences initially pause playback, and hidden tabs pause until visible again. Only the selected theme’s video is loaded.

The System / Light / Dark control matches brantly.com's `app/theme-toggle.tsx` and its control styles. It opens on mouse hover, stays open on click, and closes after selection, Escape, or an outside press. An explicit preference is saved under `artes-nobiles-theme`; System clears that override and follows live OS appearance changes. Both the page and app video follow the resolved theme.

The product navigation stays at the top once scrolled past. A compact, theme-matched logo fades in on its left and replays the same animation on mouse hover or activation. Activating it scrolls to the top in 360 ms without replaying the main logo; keyboard focus moves to the header. User scrolling interrupts the return, and reduced motion returns immediately. The compact logo is removed from the tab order while hidden, section anchors clear the sticky bar, and reduced motion preserves static logos.

Both company logos scale to 104% on mouse hover and ease back to normal on pointer leave, independently of their SVG animation. This follows the existing product hover timing and respects reduced motion.

The interactive book replaces the main Christmas Story cover, with “SEE INSIDE: Click the cover to open” above it. On desktop, its closed cover sits beside the product details; opening moves it into a full-width reading area below the text, and closing returns it beside the text. Smaller layouts keep the reader in place. The 480 ms cover movement uses a temporary fixed image so the page-turn stage keeps its scroll containment. An inner grid lets the outer product height animate with the cover, preventing a sudden scroll jump on closing. The moving cover tracks page scrolling; resize and reduced-motion changes safely finish the movement. Clicking the reader's cover opens once to the first printed page (the gift inscription), without advancing to the title spread. Desktop shows the front endpaper with the cover artwork credit beside page 1; narrow layouts show page 1 on its own. Clicking the left/right page or using the arrow controls turns backward/forward; Escape, Close book, or a click outside closes it to the front cover. Narrow layouts display one page at a time and preserve native pinch zoom. The reader includes accessible page text, supports keyboard arrows, honors reduced motion, preloads nearby pages rather than downloading the whole book at page load, and allows retry after a page-image loading failure.

Reader content is the complete Draft 152 (Canonical 152) edition, rendered from the final “Reference - Reading Order.pdf” in the Draft 152 print package: all 52 printed interior pages, six endpaper faces, and both covers, for 60 WebP images in their bound reading order. The closed cover uses the same new front-cover image as the reader. All images are 1600 × 1236; text pages use lossless encoding. Every page was rendered from this edition, including its revised artwork, Scripture, captions, picture index, and cover. No PDF, native InDesign files, print package, or private provenance is published. Rendering records and visual checks are in `output/book-reader-assets-152/_private/`; the public reading-order manifest is `dist/assets/book/152/manifest.json`. The builder verifies the complete sequence and only publishes explicitly selected assets. Previous editions’ asset URLs remain available for visitors who already have an older reader open.

Page curl and hardcover turns use the locally hosted [StPageFlip](https://github.com/Nodlik/StPageFlip) 2.0.7 module. The npm package was verified against its SHA-512 registry integrity value; its MIT license is included at `dist/assets/vendor/page-flip-LICENSE.txt`. The reader has no runtime CDN or PDF-rendering dependency.
